## Проблема

Текущая система показывает день недели для корректировок (штраф, аванс, бонус) прямо в тексте причины:
- Вместо того, чтобы хранить день отдельно: `weekday: "Пн"`
- Мы парсим его из текста: `"Штраф (Пн)"` → ищем в скобках

Это работает, но не является чистым решением. Если формат измениться, всё сломается.

### Вариант 2: Переделка Базы Данных (2-3 часа) 🏗️

**Что делать:**
Добавить отдельное поле `weekday` в таблицу `SalaryAdjustment`.

**Было:**
```
SalaryAdjustment
├── reason: "Штраф за опоздание (Пн)"  ← день спрятан в тексте
├── amount: 1000
└── type: FINE
```

**Станет:**
```
SalaryAdjustment
├── reason: "Штраф за опоздание"  ← чистый текст
├── weekday: "Пн"                 ← день отдельно
├── amount: 1000
└── type: FINE
```

**Что нужно изменить:**

1. **Schema (Prisma)**
```prisma
model SalaryAdjustment {
  // ... существующие поля
  weekday   String?  // "Пн", "Вт", etc. или null
}
```

2. **Миграция**
```bash
npx prisma migrate dev --name add_weekday_to_salary_adjustment
```

3. **API эндпоинт** (`server/src/routes/salary.ts`)
```typescript
app.post('/salary/adjustment', async (req, res) => {
  const { staffProfileId, type, amount, reason, weekday, month } = req.body;
  
  await prisma.salaryAdjustment.create({
    data: {
      staffProfileId,
      type,
      amount,
      reason,        // Just reason, no (Пн) at the end
      weekday,       // Separate field
      month,
      // ... rest
    }
  });
});
```

4. **Форма добавления корректировки** (фронтенд)
- Поле "Причина" → только текст
- Поле "День недели" → отдельный select
- Отправляем оба поля отдельно

5. **Seed скрипты**
Обновить `seed-teacher-salary.js` и `seed-teacher-salary-complete.js`:
```javascript
// Было:
reason: 'Штраф (Пн)',

// Станет:
reason: 'Штраф',
weekday: 'Пн',
```

**Плюсы:**
- ✅ Супер надёжно
- ✅ Нельзя сломать
- ✅ Чистый код
- ✅ Легко искать по базе (SELECT * WHERE weekday = 'Пн')
- ✅ Будущее-proof

**Минусы:**
- ❌ Много работы (2-3 часа)
- ❌ Нужна миграция БД
- ❌ Нужно обновить формы
- ❌ Нужно обновить seed скрипты

**Когда использовать:**
Если хотите ПРАВИЛЬНОЕ решение и не жалко времени.

function getAdjWeekday(reason: string): string | null {
